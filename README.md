# AI Traffic Violation System

## Project Description
An AI-based traffic violation detection system using YOLO and OCR.

## Features
- Vehicle detection
- Helmet detection
- Number plate detection
- Number plate OCR
- Traffic violation identification
- Streamlit web interface

## Technologies Used
- Python
- YOLO / Ultralytics
- OpenCV
- EasyOCR
- Streamlit
